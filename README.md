# Contoso Data Analysis (Initial Learning Project)

This repository contains an early-stage data analysis project using the **Contoso dataset**, created as part of my learning journey in SQL and data analytics.

The project was inspired by structured learning approaches commonly used in data analysis training programs (including resources like Luke Barousse-style SQL practice workflows). It was developed collaboratively as a learning exercise to understand real-world business data scenarios.

## 📊 Project Overview

The Contoso dataset represents a fictional retail company and includes data related to:

* Customers
* Sales transactions
* Products
* Regions
* Time-based sales performance

The goal of this project was to practice SQL-based data analysis and build foundational skills in working with relational datasets.

## 🧠 What I Worked On

During the initial phase, I focused on:

* Writing SQL queries for data exploration
* Performing joins between multiple tables
* Calculating sales performance metrics
* Analyzing customer and product behavior
* Building basic aggregated reports

## ⚠️ Project Status

This project was **not completed** in its original form.

I later decided to:

* Pause this version of the project
* Restart the analysis from scratch with a more structured and improved approach
* Rebuild the project with better design, cleaner queries, and stronger analytical focus

This repository is kept for **reference and learning progression purposes only**.
